# 小说多角色朗读

在“书籍”页上传 TXT、EPUB、FB2 或带文字层的 PDF。默认上传后用本地 Qwen 分析角色，并给角色分配 Qwen CustomVoice 声音；可以在上传前切换为 Breeze 自定义声音。

## 大文件与分析

- 上传上限为 200 MB，逐块写入临时文件。
- TXT 支持 UTF-8、UTF-16 和常见中文编码，识别中文章节标题。没有章节或自然章过长时，按最多 20,000 字符继续分章。
- 语言模型逐章、逐片分析。朗读正文始终来自原文，模型只提供角色和表演注释。
- 完成章节的分析保存在 `data/analysis/<book_id>/`。中断后重试会校验模型、原文摘要和文本覆盖，复用有效检查点。
- 无法可靠识别的片段会标为“待校对”，可以修正角色、正文、情绪和年龄阶段，再标记为已校对。

明确的旁白和已有角色的简单说话标签先用规则识别；新人物、别名揭示、复杂对白及成长阶段变化继续由 Qwen 分析。模型只返回紧凑的角色注释；输出截断时缩小待分析批次重试。中断重试会恢复原分析选项并保留已完成章节，减少重复推理。

## 角色与声音

角色和声音档案在全书范围绑定，重分析会复用已有角色和声音。年龄只大致分为少年、青年、中年、老年，结合人物成长和时间变化自然调整，不需要具体岁数；各阶段继续使用同一角色的基础音色。

角色名称会按原文校验，姓名后的动作、表情和语气不会作为独立人物。说话标签按语法主体判断，“对着某人”中的听者不能直接当作说话人；无法确定的台词统一进入待校对。嵌套引号保留整句台词，叙述中的术法、地名等引用仍由旁白朗读。

置信度按每句台词的原文证据汇总，有明确说话主体的归属才能获得高评分。主要角色按全书台词占比和最低句数判断，长篇中的两句台词不会自动成为主要角色。

BreezeBlue 提示词库包含 529 条参考描述，可按名称、声音描述或分类检索。原始 CSV 随项目保存在 `backend/data/breezeblue_voice_prompts.csv`，启动时幂等导入数据库，保留提示词、示例文稿和来源。

选择 Breeze 后，首次试听或生成会创作并保存角色参考音频。后续章节复用该参考音频；修改声音设计会创建相应的新参考。参考音频和生成音频都存放在项目的数据目录中。

## 生成与播放

可以生成全书，也可以选择部分章节，并设置 1–4 个并行任务。单机模型推理受控执行，各章节独立记录进度。失败片段可以重试，修改过的片段可以重新生成；已完成的音频可以在章节页播放和导出。

导出支持 M4B、整本 MP3 和分章 MP3 压缩包。音频按片段写入磁盘，再流式编码；完成后原子保存成品，失败时保留上次导出。已完成的导出信息保存在 `data/exports/<book_id>/export.json`，刷新页面或重启服务后仍可下载。

## Breeze 本地运行环境

VoiceIt 用持久子进程连接已有的 Breeze mlx-audio 环境。模型加载和发声都在该进程的固定线程运行。环境变量用于配置现有安装：

```bash
export VOICEIT_BREEZE_PYTHON=/path/to/mlx-audio/.conda/bin/python
export VOICEIT_BREEZE_SOURCE_DIR=/path/to/mlx-audio
export VOICEIT_BREEZE_MODEL_DIR=/path/to/Breeze-TTS-2-mlx-8bit
```

模型文件缺失时会报告本地路径错误。项目启动脚本可加载这些变量；Breeze 运行时与 VoiceIt 的 Python 依赖分开管理。
